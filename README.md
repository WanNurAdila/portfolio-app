# portfolio-app

Personal portfolio site for Wan Adila — a front-end developer based in Kuala Lumpur, specializing in Flutter mobile apps and React interfaces.

Built with React 19, TypeScript, and Vite.

## Sections

- **About** — background, tools, and approach
- **Work** — selected personal projects (currently: Rhythm App)
- **Archive** — professional work from previous roles, shown as screenshots
- **Path** — career timeline
- **Contact** — email, resume download, GitHub

## Stack

- React 19 + TypeScript
- Vite
- ESLint + Prettier

## Dev

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |
